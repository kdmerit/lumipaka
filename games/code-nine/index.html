HOW TO PLAY

조작 방법

화면의 숫자판을 터치하거나 클릭해 숫자를 입력 · PC에서는 1~9 숫자키, Enter, Backspace, Delete 사용 · PAUSE 또는 P / ESC로 일시정지

ABOUT

게임 정보

이 게임은 별도 설치 없이 모바일과 PC 브라우저에서 플레이할 수 있습니다.

PLAY GUIDE

게임 플레이 가이드

CLASSIC과 BLITZ는 중복 없는 세 자리 숫자, HARD는 중복 없는 네 자리 숫자를 맞히세요. 숫자와 위치가 모두 맞으면 STRIKE, 숫자만 맞으면 BALL, 공통 숫자가 없으면 OUT입니다.

RULES

게임 규칙

  • CLASSIC과 HARD는 최대 10번 안에 정답을 맞혀야 합니다.
  • BLITZ는 100초 안에 정답을 맞히며 시도 횟수는 제한하지 않습니다.
  • 모든 숫자는 1부터 9까지 사용하며 한 코드 안에서 같은 숫자를 다시 사용할 수 없습니다.
  • 정답을 맞힌 횟수와 모드별 최고 기록은 같은 브라우저에 저장됩니다.
TIPS

플레이 팁

  • OUT이 나오면 입력한 숫자 세 개 또는 네 개를 후보에서 먼저 지우세요.
  • BALL이 나온 숫자는 위치를 바꿔 다시 시도하고, STRIKE 숫자는 위치를 유지하세요.
  • BLITZ에서는 매 추측 전에 지금까지의 기록을 빠르게 비교해 중복 검사를 줄이세요.
