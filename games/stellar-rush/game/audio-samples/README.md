# Stellar Rush 발사음 후보

아군 전투기 기본 발사음 후보 5개입니다. 현재 게임에는 아직 연결하지 않았으며, 선택 후 `game.js`의 발사 효과음으로 교체합니다.

| 파일 | 질감 | 길이 |
| --- | --- | ---: |
| `shot-01-neon-pulse.wav` | 짧고 밝게 하강하는 전자 펄스 | 240ms |
| `shot-02-ion-snap.wav` | 빠르게 상승하는 이온 스냅 | 180ms |
| `shot-03-plasma-burst.wav` | 거칠고 묵직한 플라즈마 방출 | 310ms |
| `shot-04-retro-laser.wav` | 고전 슈팅 게임풍의 날카로운 레이저 | 270ms |
| `shot-05-nova-needle.wav` | 얇고 긴 잔향이 있는 고음 발사음 | 360ms |

모든 파일은 44.1kHz, mono, 16-bit PCM WAV입니다.
