ABOUT LUMIPAKA

LUMIPAKA 소개

LUMIPAKA는 설치와 회원가입 없이 짧게 즐길 수 있는 오리지널 HTML5 웹게임을 모아 제공하는 플랫폼입니다.

브라우저에서 바로 플레이

모바일과 PC 브라우저에서 같은 게임을 실행할 수 있도록 반응형 화면과 터치 조작을 기본으로 설계합니다. 게임은 별도 앱 설치 없이 게임 상세 페이지에서 바로 시작할 수 있습니다.

오리지널 게임 중심

LUMIPAKA의 게임은 짧은 규칙과 빠른 재도전을 중심으로 직접 기획하고 제작합니다. 각 게임 페이지에서 조작 방법, 규칙, 플레이 팁과 업데이트 정보를 확인할 수 있습니다.

가볍게 운영하는 플랫폼

플랫폼은 정적 웹 기술과 GitHub Pages를 기반으로 운영합니다. 로그인, 게임 계정, 서버 점수판 없이도 게임을 이용할 수 있도록 구성하고, 게임별 배포 파일은 다른 웹 플랫폼과 모바일 앱 패키징에도 사용할 수 있게 유지합니다.
